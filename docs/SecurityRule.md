## Quy ước chung (mọi stream)

1. **Type 1** — lỗ trên code đã ship: sửa trong sprint đang mở hoặc hotfix có ID.  
2. **Type 2** — defer: ghi backlog + gắn sprint sau; không “nhớ trong chat”.  
3. Mỗi sprint có thể có `SECURITY_FOLLOWUPS.md` mirror nếu phát sinh mid-sprint.  
4. Prove-done security = test tự động hoặc manual có checklist, không chỉ “đã review cảm giác”.  
5. Rule thực thi chung: [`Implement_docs/lessonlearn.md`](Implement_docs/lessonlearn.md) (đặc biệt ownership, error contract, rate limit patterns).
